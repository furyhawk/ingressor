Q: How do I run this?

Q: How is this different from Streamlit?
A: See MIGRATION_GUIDE.md - Better performance, state management, deployable

Q: How do I deploy to production?
A: See DEPLOYMENT.md - Multiple options available

Q: Can I still use the old Streamlit app?
A: Yes, it's in app/ folder - run: streamlit run app/streamlit_app.py

Q: What are the system requirements?
A: Python 3.11+, 4GB RAM, ~4GB disk space

Q: Does it support multi-user?
A: Yes - Reflex handles concurrent connections

Q: How do I add new features?
A: See reflex_app.py - edit MarkerState and UI components

Q: What about security?
A: Files processed locally, not stored - See README.md security section


🆘 TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════════

Problem: Models not loading
Solution: First run downloads ~2GB models - be patient

Problem: Port 3000 already in use
Solution: reflex run --port 3001

Problem: Import errors
Solution: uv sync (or pip install -e .)

Problem: File upload fails
Solution: Check max file size in configuration

Problem: Docker build fails
Solution: Check disk space, run: docker system prune

See DEPLOYMENT.md for more troubleshooting
